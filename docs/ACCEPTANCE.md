# 浏览器手动验收

以下项目需要在 Chrome 中验证；Node 测试不能代替真实的音频捕获和听音测试。

## 整体响度与突发强音

1. 在轻声课程、响亮音乐、短视频间切换，确认稳定响度更接近；呼吸、节拍和短暂停顿不应导致音量来回抽动。强音后回升较慢属于预期行为。
2. 轻声后插入强音或广告，分别验证默认模式和整页接管。默认模式每约 25 ms 采样，后台计时器可能延迟；接管模式应在突发声前平滑衰减，不能只检查是否达到满刻度。
3. 暂停 30 秒后恢复、切换播放列表，确认不会重新抬高增益。设置 30%、70%、100% 时，接管模式突发声上限也应随之变化。
4. 用耳机检查人声、音乐和左右声道定位，确认没有新增咔哒声或明显抽吸；接管模式增加约 10 ms 延迟。合成音自动测试通过不代表已经完成此项听音验收。

## 默认模式界面（1.4.1）

1. 默认启用时，普通网页不显示「接管当前网页」卡片或重复开启提示，直接查看网页音量动态列表。
2. 关闭默认模式后显示当前网页的手动接管入口；已有整页接管时保留停止入口，重新打开默认模式也能停止已有接管。

## 数字标与分贝上限（1.4.0）

1. 关闭弹窗，不调用整页接管，新打开普通音视频网页后工具栏显示 1；同页动态播放器和 iframe 不重复计数；第二个有播放器的网页显示 2。只有 iframe 含播放器时也应计数，移除最后一个播放器/iframe 后清除。
2. 暂停或静音仍计为管理中；停止单页/关闭默认模式排除默认会话，恢复后重新计数；切换整页接管保持同页只计一次。关闭标签页、导航到无媒体页面后清理旧计数。
3. 后台 worker 重启后，不打开弹窗时徽标仍保留；设置变更能从会话存储恢复注册信息。悬停图标的文字与数字一致。
4. 输入 −30 dBFS 或拖动峰值上限滑块，确认重开面板后设置保留。提高百分比或独立网页音量不能绕过已设置的上限；关闭响度均衡仍限制峰值。
5. 默认模式播放稳定测试音时，音量应根据采样峰值下调；无法读取音频的播放器应保守衰减。默认模式不保证阻止突发峰值，界面应明确这一限制。
6. 整页接管模式将上限降至 −40 dBFS，检查音频线程的输出采样峰值不超过约 0.01；输入突变时也不越过该值。RMS 读数不等于峰值，且多个网页混音总峰值不受此逐音源上限保证。

## 输出参考（1.3.0）

1. 确认每页输出电平下方显示「输出起始参考 −30～−18 dBFS」，当前状态对应低于、范围内、高于或很高；范围内不应显示「听力安全」。
2. 关闭自动均衡并播放较响的本地测试音，检查高于 −18 dBFS 时提示调低、输出条变为黄色；超过 −6 dBFS 为更突出的颜色。这里只评价 RMS 数字电平，不推断实际声压或峰值削波。
3. 静音、停止、暂停无输出、不可读取音频时，各自显示正确状态，不将未知数值当作安全。
4. 面板有 80 dB(A) / 40 小时每周的成人实际声级参考、WHO 来源链接，以及 dBFS 无法判断耳边听力安全的说明；多网页同时播放也不宣称总声暴露安全。

## 网页列表和独立调控（1.2.0）

1. 默认模式下播放两个网页，打开面板，确认两页都有行、标题、设定音量、输入/输出电平及变化曲线；同页 iframe 汇总为一行，不重复显示。
2. 每行点「−」「+」确认每次变化 10 个百分点，仅对应网页变化；边界限于 0–100%。修改统一音量后独立网页保持自己的音量，点击「跟随统一」恢复联动。
3. 点「静音」确认仅对应网页无声，按钮切为「取消静音」，电平输出为零；取消静音恢复之前的音量值，其他网页正常播放。自动模式和整页接管都需验证。
4. 点行内「停止」确认停止该页所有处理，其他页不受影响，该行可「恢复」。刷新被停止网页后仍不自动开启；恢复后默认模式生效，整页接管需重新点击授权。
5. 暂停播放、移除 iframe、导航、关闭标签页后数据不残留。不能读取的电平显示「不可读取」，不可误报成正在静音或伪造测量。
6. 关闭弹窗时不持续轮询网页。停止后台 worker 后重开面板，单页控制状态和自动列表可恢复；取消浏览器标签页静音时列表同步更新。

## 默认网页模式（1.1.0）

1. 重新加载扩展并刷新网页，确认「所有网页默认启用」开启；不点击整页接管，普通音视频播放器音量自动跟随扩展。
2. 在两个新网页、动态插入的播放器、iframe 和开放 Shadow DOM 中验证默认生效。
3. 修改统一音量并设为零，检查所有自动控制的播放器同步变化；静音设置不应被取消。
4. 关闭默认模式，确认恢复各播放器之前的音量；重新打开后恢复自动控制，重启后保留设置。
5. 可分析的同源音频应自动趋近目标响度；跨域/DRM 音频无法分析时仍有声音且保留统一音量，纯 Web Audio 需使用整页接管。
6. 默认模式中手动启动整页接管，确认播放器原音量恢复，由接管处理器统一控制；停止接管后恢复默认模式，不产生重复增益。

## 增强均衡（整页接管）

1. 加载 `extension`，确认扩展页面无 service worker 报错，弹窗能打开。浏览器内部页的「启用」按钮不可用。
2. 打开有声视频 A，将播放器音量调到非零；点击「增强均衡：接管当前网页」后声音继续播放，徽标为 1。关闭弹窗后音频继续。
3. 打开明显更响/更轻的视频 B，点击启用，徽标为 2。切换播放 A/B，数秒后稳定响度应更接近。
4. 将统一音量设为 30%、70%、100%，确认两个已启用网页都随之变化。调至 0 后两个网页都静音；恢复后声音返回。
5. 关闭「自动响度均衡」，确认原始强弱差异恢复，但统一音量仍有效。重新打开均衡后数秒内恢复收敛。
6. 在 A 中暂停 30 秒再继续，确认不会因静音期间自动提升增益而突然大声。突然切入强音时检查峰值保护。
7. 在面板停止 A，确认 A 返回默认模式且 B 继续接管；点击「停止全部接管」，默认模式仍管理的网页应继续计入徽标。关闭默认模式时才恢复原声；停止后检查 offscreen 页面已释放。
8. 关闭被接管的标签页，确认列表/徽标更新；从 Chrome 的共享提示停止捕获，确认清理且原声恢复。
9. 接管中刷新/导航网页，观察流是否继续；若 Chrome 结束捕获，列表应清除，可重新点击启用。重启浏览器后设置保留、需要重新启用标签页。
10. 快速重复点击启用、停止和滑块，确认没有重复音频、幽灵会话或无声残留。静音标签页时面板应显示静音提示。
11. 在 `chrome://extensions/` 中停止 service worker 后重新打开弹窗，确认现有流仍在列表中，统一音量仍可控制。
12. 测试受保护内容/Chrome 网上应用店，捕获失败时显示错误且不残留会话。关闭默认模式后，未接管的网页不应受音量设置影响。

为了安全地测试强音，请先降低系统音量。多页同时播放的混音总峰值由系统处理，扩展只对每个接管流做峰值限制。
