# Balance Voice · 网页音量均衡

一个可直接加载的 Chrome Manifest V3 扩展。让多个网页共用一个输出音量，并根据实际音频响度自动调整增益，减少切换视频、音乐、直播时的音量落差。

## 安装

需要 **Chrome 116 或更高版本**。

1. 打开 `chrome://extensions/`，开启右上角「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目的 **`extension` 文件夹**。
3. 在扩展菜单中固定 Balance Voice，打开一个正在播放声音的网页。
4. 「所有网页默认启用」预设为开启，新网页里的普通音视频播放器会自动使用统一音量，无需逐页点击。
5. 可在弹窗调整统一音量，或关闭「所有网页默认启用」。对于纯 Web Audio 页面，可先关闭默认模式，再使用「增强均衡：接管当前网页」；接管后可重新开启默认模式。

也可运行 `npm run package`，将 `dist/balance-voice-1.4.1.zip` 解压后加载。ZIP 不是可双击安装的签名 CRX。

**从旧版升级**：在 `chrome://extensions/` 点击本扩展的重新加载按钮，随后刷新已打开的网页。新版增加普通网页音视频自动控制，Chrome 可能要求确认网站访问权限；需允许在所有网站运行，才能默认生效。

## 使用

- **所有网页默认启用**：默认开启，作用于 HTTP / HTTPS 网页中的 HTML 音视频元素，包括动态插入的播放器、匹配的子框架和可发现的开放 Shadow DOM。开启时不再显示重复接管卡片，直接查看网页音量列表；已接管的当前网页仍显示停止入口。关闭后恢复播放器此前的音量，不改变网页静音设置；重新开启立即生效。
- **统一输出音量**：0–100%，跟随统一设置的播放器和整页接管会话同步更新；0 为静音。设置保存在本机，重启浏览器后保留默认开关。已单独调过音量的网页保持自己的设定，可点击「跟随统一」恢复同步。
- **最大输出峰值**：可用数字输入或滑块设置 **−60～0 dBFS**，默认 **−1 dBFS**；数值越负，上限越低。它限制数字信号的峰值幅度，不是百分比换算，也不是耳边分贝；列表原有输入/输出数值是 RMS，正弦音受到峰值限制时，其 RMS 通常还低约 3 dB。所有仍受管理的音源（包括独立音量网页）共用此上限，关闭响度均衡后限幅仍生效。设置保存在本机。
- **上限的精度**：整页接管在音频线程逐渲染块前瞻限制采样峰值，降低上限从下一处理块生效；默认模式每约 100 ms 根据播放器采样峰值调节音量，背景计时器也可能延迟，无法严格拦截突发峰值。分析不可用或尚未开始时，按满刻度假设保守衰减播放器音量，不能验证实际峰值。此上限按音源独立生效，不限制多个音源/多个网页/系统其他应用混合后的总输出，系统音量、耳机放大或耳边声压也不受控制。需要严格限制某网页的数字采样峰值时，使用整页接管。
- **自动响度均衡**：默认模式通过 `captureStream()` 读取可访问的播放器音频，仅分析，不接管播放，再调整播放器音量。无法分析时保留统一音量。自动模式播放器音量上限为 100%，特别轻的声音可能无法提升到目标；音量采样不是逐样本峰值保护。
- **增强均衡**：可手动接管当前标签页的完整音频（包括 Web Audio），使用音频线程做 RMS 均衡、平滑和峰值保护。它仍需逐页点击授权。接管期间自动模式退出该标签页，避免重复调节；停止后恢复默认模式。
- **网页音量动态**：列表同时显示有音视频元素的默认模式网页和整页接管会话，按标签页汇总 iframe 数据。显示当前设定音量、输入/输出 dBFS 电平、近期输出变化曲线及模式。默认模式的输出根据播放器音量估算，多个音源按能量近似汇总，不代表扬声器声压；跨域/受保护音频等不能读取时明确显示「不可读取」。暂停时显示等待播放，静音时输出为零。
- **输出参考与听音安全**：每行显示产品设定的 RMS 起始参考 **−30～−18 dBFS**。高于 −18 dBFS 提示调低，高于 −6 dBFS 进一步突出显示；低于参考仅说明数字电平较低，不鼓励盲目调高。此范围围绕均衡器的常见输出设定，是数字信号比较辅助，不是医学安全线，也不表示已检测到峰值削波。静音、停止或无法读取时分别显示对应状态，不给出安全判断。
- **实际声级参考**：面板引用 [WHO 听音安全说明](https://www.who.int/news-room/questions-and-answers/item/deafness-and-hearing-loss-safe-listening)及 [WHO/ITU 成人声暴露参考](https://www.itu.int/epublications/publication/itu-t-hstp-sld-venue-2024-04-guidelines-for-safe-listening-at-venues-and-events)：80 dB(A) 对应每周累计 40 小时的成人参考暴露量，声级越高应缩短时间。**插件不能读取系统音量、耳机灵敏度或耳边声压，不能从 dBFS 换算 dB(A)、推算剩余安全时长或保证听力安全**。输出处于数字参考范围时，实际听音仍可能过响。WHO 链接仅在用户点击后打开。
- **独立控制**：每行提供静音/取消静音、调低/调高（每次 10 个百分点）、跟随统一、停止/恢复。静音保留原来的音量值；停止会恢复网页播放器的原音量，并阻止该标签页自动重新开启。恢复回到默认模式，纯 Web Audio 的整页接管仍需重新点击授权。上方「停止整页接管」和「停止全部接管」保留回到默认模式的行为。
- **单页设置与刷新**：独立音量和单页停止状态在当前浏览器会话中保存，网页刷新或后台 worker 重启后保留；关闭标签页后清理，浏览器重启后重新跟随统一设置。静音与浏览器标签页静音状态同步，停止处理不会自动取消静音。
- **工具栏数字标**：显示默认模式管理的网页与整页接管网页的总数，同一标签页只计一次（多个播放器/iframe/接管切换不会重复计数）；包含暂停或静音但仍受管理的网页。计数由媒体元素的增删、页面离开和设置变更主动更新，关闭弹窗后依然生效；单页停止或关闭默认模式会排除对应的默认会话。注册信息保存在浏览器会话中，后台 worker 重启不会丢失。悬停图标可看到正在管理的网页数。
- **后台运行**：关闭弹窗、切换标签页后继续处理。关闭被接管的标签页或浏览器终止共享时自动释放音频流；普通播放器暂停/移除后释放分析流。

默认模式开启时，网页播放器的音量滑块由扩展管理；之后请使用扩展调节。网页自身静音或浏览器标签页静音时，扩展不会取消静音。

## 浏览器限制与效果边界

- Chrome 要求用户先在当前标签页调用扩展，才能开始 `tabCapture`，仅「增强均衡」需要逐页点击；普通音视频的默认模式无需此步骤。关闭默认模式不会停止已经授权的整页接管。
- 当前版本只允许普通 HTTP / HTTPS 网页。浏览器设置页、扩展页面和本地文件未开放支持；受保护内容、商店页面或其他扩展占用音频捕获时，也可能无法接管，会在面板显示错误。
- 默认模式不能控制纯 Web Audio、未连接到文档的 `new Audio()`、封闭 Shadow DOM 等播放器。跨域/DRM 音频可能禁止分析，此时保持播放器音量控制；不尝试绕过跨域或内容保护。浏览器若阻止网页 AudioContext 自动运行，需网页获得播放交互后才可分析，否则保持统一音量。
- 这是实时 RMS 均衡，不是 EBU R128 / LUFS 测量，不保证不同频谱的声音主观听感完全一致。新声音需要短暂时间收敛；不是降噪器，较安静的背景噪声也可能被适度提升。
- 百分比是扩展输出增益，不是系统音量或耳机的物理声压。扩展不修改系统音量；多个网页同时播放时，混合后的总响度仍可能增加。
- 有少量音频处理延迟。停止或重新加载扩展时可能出现短暂停顿。首次启用如果遇到系统阻止音频引擎启动，重新点击启用即可重试。

## 隐私与权限

音频流仅在本地 Web Audio 中实时处理，不录制、不持久保存、不上传；没有分析服务、远程脚本、账号或网络请求。

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 用户调用扩展后获取当前网页信息 |
| `tabCapture` | 接管当前网页的音频输出 |
| `offscreen` | 在弹窗关闭后继续处理和播放音频 |
| `storage` | 本机保存统一设置，浏览器会话内保存单页音量与停止状态 |
| HTTP / HTTPS 内容脚本匹配 | 在普通网页及其匹配子框架内自动调节音视频播放器，支持默认开启 |

新版在 HTTP / HTTPS 页面注入隔离环境的本地内容脚本，需网站访问权限，不读取表单、账号、密码或发送网页内容。Chrome 在整页接管时可能显示正在共享/捕获标签页，这是音频接管的浏览器提示。

## 开发与验证

无第三方运行依赖，Node.js 20+：

```sh
npm test
npm run check
npm run package
```

可选浏览器集成测试（默认使用 Windows 已安装的 Chrome，可用 `BROWSER_PATH` 指定路径）：

```sh
npm run test:browser
npm run test:browser -- --auto
npm run test:browser -- --audio
```

浏览器测试通过官方 DevTools API 在独立临时配置中加载扩展，不使用个人浏览器配置。`--auto` 检查默认启用、动态播放器、iframe、电平数据、列表按钮（静音、调高/调低、停止/恢复、跟随统一）、播放器 RMS 均衡和接管互斥；`--audio` 检查真实捕获、接管静音/单页音量、10 倍输入强弱变化、双标签页音量和资源释放，两者可同时使用。运行前可调低系统音量。弹窗截图保存到 `dist/popup-preview.png`。

`extension/automatic.js` 负责默认网页播放器控制和非破坏性音频分析；`background.js` 负责消息、设置同步和捕获生命周期；`offscreen.js` 管理音频流；`dsp.js` 实现 RMS 均衡、增益平滑、静音门限和立体声联动限幅；`normalizer-worklet.js` 在音频线程执行处理；`popup.*` 为中文面板。

自动化测试使用合成音频验证响度收敛、瞬时峰值、静音、立体声与设置边界。真实浏览器需按 [手动验收清单](ACCEPTANCE.md) 验证捕获权限、跨页和音频设备行为。

API 依据：[Chrome tabCapture](https://developer.chrome.com/docs/extensions/reference/api/tabCapture)、[后台音频捕获示例](https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture)、[Offscreen 文档](https://developer.chrome.com/docs/extensions/reference/api/offscreen)。
